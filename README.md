# 追悟时空智能算法平台

用于本机答辩演示的工业视觉与空间感知平台，包含真实边坡算法及明确标注的案例和交互演示。

## 拉取后的首次启动

1. 将仓库克隆到本机目录（路径不必是 D:\Company\Website）。
2. 安装 Python 3.12（64 位，包含 Windows Python Launcher）。
3. Windows 双击 `首次安装.cmd`：建立虚拟环境、安装依赖、生成合成验证点云。首次安装需要联网。
4. 双击 `启动演示.cmd`，访问 http://127.0.0.1:8080 。
5. 保持服务窗口打开；关闭窗口即可停止服务。8080 已被占用时，先关闭旧服务。

也可手工运行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe generate_sample.py
.\.venv\Scripts\python.exe server.py
```

## 交接范围

- `dist/`：前端、演示图片，以及 stoneData 的 67 张原始溜井口图片和缩略图。石块数据没有标注或模型权重。
- `server.py`、`algorithms/`：本机边坡计算服务和算法。只监听回环地址，不可直接作为公网服务。
- `generate_sample.py`：生成合成点云，无需下载真实矿区点云。
- `/#assistant`、`/#billing`：规则问答、模拟会员及 Token；不调用真实大模型或支付。
- `/#creative`：本地海报模板排版、SVG 和需求文本导出；未接入 AI 图片生成。素材和文案刷新后清空。
- 不提交虚拟环境、运行结果、聊天账户、本机部署信息和原始压缩附件。账户数据存在浏览器中，不随 Git 传递。

## 演示验收

- 打开首页及五个场景，确认案例图片正常。
- 边坡工作台选择合成点云并运行，查看任务结果、预览和 GeoJSON。
- 数据管理查看 67 张石块样本；真实检测按钮保持待接入状态。
- 模拟会员开通、充值和规则问答；刷新后账户应保留。
- 海报工作台修改文案和画幅，检查预览及导出。

## 算法与已有验证说明

# 追悟时空智能算法平台答辩雏形

项目位置：D:\Company\Website

启动：双击“启动真实算法.cmd”或“启动演示.cmd”，浏览器访问 http://127.0.0.1:8080 。真实算法必须通过本机服务运行。直接打开 dist/index.html 可查看静态前端，不能执行真实算法。

推荐演示：平台首页 → 场景应用 → 露天矿边坡线提取 → 选择合成台阶点云或本机矿区点云 → 运行真实算法 → 查看预览与统计 → 下载 GeoJSON、运行参数及报告。系统设置中可进入展示模式，Esc 返回。

包含首页、算法中心、五个案例、数据预览、任务记录、项目列表、成果报告、资料问答、系统设置。前端为 HTML/CSS/JavaScript；本机服务为 Python。项目 .venv 内已安装真实边坡算法依赖；requirements.lock.txt 记录已验证版本。

真实接入：用户提供的 slopeline_tool_自动补线_20260917.zip 中坡顶/坡脚提取、增强续接、多尺度增强和自动补线模块已在 algorithms/ 内接入，核心源码未修改。服务调用 run_slope.py，真实任务结果保存在 runtime/results/，刷新与重启后可查看。当前只接入边坡几何算法，AOI、石块识别等仍为资料回放，尚未提供对应可执行代码和模型。

点云支持：二进制 PLY（小端/大端），LAS 1.2–1.4 的点格式0–3，或包含这些文件的 ZIP。不支持 ASCII PLY、LAZ、PCD。网页输入本机绝对路径，服务只读输入文件，输出限定在项目任务目录。一次执行一个任务，可取消；超过30分钟自动终止。大型数据需结合内存调整网格分辨率。

坐标与区域：默认仅输出 ENU 局部坐标，单位米，不套用原配置中的矿区地理原点。原矿区局部种子区域和手工约束在通用运行中关闭，避免应用到错误矿区；若需复现原矿区精细参数，须核对点云与配置坐标后再启用。

数据口径：data/synthetic_benches.ply 是生成的13.5万点合成台阶面，仅用于真实流程验证。已验证结果为3条坡顶线、3条坡脚线、自动补线0条、总长度548.83m，不代表矿区实测性能。原资料的61/50条等案例数值与本次结果分别显示。自动补线0条表示没有候选通过算法约束。

其他边界：没有交互三维引擎、训练服务、账户认证或大模型服务。首页统计和项目状态为示例。AOI指标为要求；边坡和石块数为原资料实例；扫描指标为研发目标。首页矿山与横幅使用参考图局部，案例图来自所提供资料；扫描页图片为资料点云示意，非该研发装备成果。

当前接口：POST /api/jobs 提交真实边坡任务；GET /api/jobs 查询任务列表；GET /api/jobs/:id 查询状态与结果；GET /api/jobs/:id/files/:filename 读取成果；POST /api/jobs/:id/cancel 取消。服务只监听127.0.0.1:8080，不向互联网发送数据。

资料原文保留在用户提供的位置，网页仅包含演示所需效果图，不包含完整商业计划书和原始附件。

会员与智能体演示：访问 /#assistant 或 /#billing。会员开通、支付、Token充值与对话消耗均为模拟；套餐价格为演示设定，不调用支付平台。账户与聊天历史保存在当前浏览器 localStorage，初始赠送5000模拟Token；与外部模型账户无关。智能体为本地资料与规则问答，可读取真实边坡任务结果，没有连接大语言模型。已验证开通专业会员、轻量充值包、对话消耗和刷新保留。
